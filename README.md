# Python 小车模拟器

## 功能

支持前进、倒车、车身旋转、边界与障碍物碰撞检查、暂停、重置，以及路程和轨迹显示。

## 运行

需要支持 Tkinter 图形界面的 Python 环境。本项目在 Windows、Python 3.14.2 下验证，使用标准库，无需安装第三方库。

在项目目录运行：

```powershell

python main.py

```

本机也可以双击“启动小车.bat”。该启动文件包含本机 Python 路径，其他电脑请使用上面的命令。

## 操作

| 按键 | 功能 |
|---|---|
| W | 增大步长，最高为 10 |
| S | 减小步长，最低为 -5；负数表示倒车 |
| 左右方向键 | 每次转向 10 度 |
| 空格 | 停车 |
| P | 暂停或继续，保留步长 |
| R | 重置位置、方向、路程和轨迹 |
| 关闭窗口 | 退出程序 |

## 限制

这是编程学习用的简化运动模型，允许原地转向，不模拟真实车辆动力学。

碰撞检查使用车身的外接矩形，斜着靠近障碍物时可能提前停车。
